# 🦠 COVID-19 Analysis Dashboard — Power BI

## 🎯 Project Overview
An end-to-end, production-ready Power BI report that gives public health
analysts and decision-makers a single interactive view of global confirmed
cases, death rates, recovery trends, and geographic spread — all in one
cohesive analytics application.

## 📌 Business Problem
Analysts needed a unified dashboard to track confirmed, death, and recovery
counts globally, compare pandemic progression across countries, monitor
case trends and peak periods over time, and identify the most impacted
regions worldwide.

## 📁 Dataset
- Daily confirmed, death, recovered, and active case counts by country
- Geographic data by Country and Region
- Date table for time intelligence calculations
- Source: Johns Hopkins University COVID-19 Dataset

## 🛠️ Tools & Technologies
- **Visualization:** Power BI Desktop
- **DAX Measures:** Total Confirmed, Total Deaths, Total Recovered,
  Active Cases, Death Rate %, Recovery Rate %
- **Data Preparation:** Power Query (M Language) for data cleaning
  and type formatting
- **Design:** Dark enterprise theme with custom visuals

## 📊 Dashboard Pages
| Page | Description |
|------|-------------|
| 🏠 Cover | Branded entry page with navigation button |
| 1️⃣ Global Overview | KPI cards, World Map by country, Top 10 countries bar chart, daily trend line |
| 2️⃣ Country Deep-Dive | Confirmed vs. Deaths vs. Recovered trend, Death Rate % and Recovery Rate % KPIs |
| 3️⃣ Time Analysis | Area chart for global daily cases, monthly peaks column chart, year/month slicers |

## 🔍 Key Insights
- Death Rate % and Recovery Rate % tracked and compared across all countries
- Clear identification of pandemic waves and global peak periods
- Top 10 most impacted countries ranked by confirmed cases
- Geographic bubble map showing spread intensity by country

## 🎨 Design Highlights
- Dark enterprise theme with structured page backgrounds
- World map visual for geographic distribution of cases
- Consistent slicer set: Country, Region, Date Range
- Conditional formatting on Death Rate and Recovery Rate metrics
- Bookmark-based navigation between all pages
